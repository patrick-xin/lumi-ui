## 基本用法

```tsx
import { RadioGroup, Radio } from "@/components/ui/radio"
```

```tsx
<RadioGroup>
  <Radio />
  <Radio />
</RadioGroup>
```

<Tabs defaultValue="common">
  <TabsList>
    <TabsTab value="common">常用组合</TabsTab>

  </TabsPanel>

<Callout variant="info" title="提示">
`Radio` 必须始终放在 `RadioGroup` 内使用。
</Callout>

<Callout variant="warning" title="警告">
表单控件必须具备可访问的名称。建议使用 [`<Fieldset>`](/docs/components/form-input/fieldset) 和 [`<Field>`](/docs/components/form-input/field) 来提供可见的文本标签和描述，或者用 `aria-label` 属性作为替代方案。
</Callout>
