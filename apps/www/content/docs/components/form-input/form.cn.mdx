## 基本用法
Form 通常与 [Field](/docs/components/form-input/field) 一同组合使用。

```tsx
import { Form } from "@/components/ui/form"
import { Field, FieldLabel, FieldControl, FieldError, FieldDescription } from "@/components/ui/field"
```

```tsx
<Form>
  <Field name="username">
    <FieldLabel>用户名</FieldLabel>
    <FieldControl required minLength={3} />
    <FieldDescription>公开显示的名称。</FieldDescription>
    <FieldError />
  </Field>
</Form>
```
