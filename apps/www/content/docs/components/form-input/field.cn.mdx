## 组件结构

```tsx
<Field>
  <FieldLabel />
  <FieldControl />
  <FieldDescription />
  <FieldItem />
  <FieldError />
  <FieldValidity />
</Field>
```

<Callout variant="warning" title="警告">
  表单控件必须有可访问的名称，才能被辅助技术正确识别。`<FieldLabel>` 和 `<FieldDescription>` 会自动为其关联的控件分配可访问名称和描述。
</Callout>

## API 参考

| 组件 | 描述 |
| :--- | :--- |
| [`Field`](https://base-ui.com/react/components/field#root) | 组合字段的所有部分。渲染一个 `<div>` 元素。 |
| [`FieldLabel`](https://base-ui.com/react/components/field#label) | 与字段控件自动关联的可访问标签。渲染一个 `<label>` 元素。 |
| [`FieldControl`](https://base-ui.com/react/components/field#control) | 需要被标签关联和校验的表单控件。渲染一个 `<input>` 元素。你也可以省略这一部分，改用任意 Base UI 输入组件。例如 `Input`、`Checkbox` 或 `Select` 等都能与 `Field` 开箱即用地协同工作。 |
| [`FieldDescription`](https://base-ui.com/react/components/field#description) | 包含字段附加信息的段落。渲染一个 `<p>` 元素。 |
| [`FieldItem`](https://base-ui.com/react/components/field#item) | 在复选框组或单选框组中，将单个选项与其标签和描述组合在一起。渲染一个 `<div>` 元素。 |
| [`FieldError`](https://base-ui.com/react/components/field#error) | 当字段控件校验失败时显示的错误信息。渲染一个 `<div>` 元素。 |
| [`FieldValidity`](https://base-ui.com/react/components/field#validity) | 根据字段的校验状态显示自定义信息。`children` 必须是一个接收字段校验状态作为参数的函数。 |
