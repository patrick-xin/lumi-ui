## 用法

```tsx
import { ScrollArea } from "@/components/ui/scroll-area"
```

```tsx
<ScrollArea className="h-[200px] w-[350px] rounded-md border p-4">
  小丑开始在深夜潜入城堡，把笑话散落在各个角落：国王的枕头下、汤碗里，甚至是皇家洗手间里。
  国王大发雷霆，却始终拦不住小丑。直到有一天，王国里的人们发现，小丑留下的笑话实在太好笑了，
  忍不住捧腹大笑。一旦笑起来，就再也停不下来。
</ScrollArea>
```
